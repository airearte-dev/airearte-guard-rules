# Claves públicas

Un fichero por clave: `<id>.pub` con la clave pública Ed25519 en base64. El nombre es el identificador (16 primeros
caracteres hexadecimales del SHA-256 de la clave); las herramientas rechazan un fichero cuyo nombre no coincida.

Aquí sólo hay claves **públicas**. Las privadas no están en este repositorio, ni en ningún servidor, ni en el correo.
